# Content Repurposer Web App

Simple AI tool: paste content → get X thread, LinkedIn post, newsletter, video scripts.

## Deploy to Vercel
1. Import this repo into Vercel.
2. Set env vars: LLM_API_KEY (required), optionally LLM_API_URL and LLM_MODEL for OpenAI-compatible (e.g. xAI).
3. Update CHECKOUT in index.html to your LemonSqueezy link.

Free tier: 3 uses (localStorage). Pro unlocks unlimited.

Pricing: ~$9/mo or $19 for 100 credits.

Also viable as done-for-you service $49-149.

Note: free limit is client-side (bypassable); add server-side auth for production.
